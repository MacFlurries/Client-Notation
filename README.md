**Client Notation** is a lightweight, frontend-driven web application designed to **track team standups**, sprint requirements, and dairy operations data through a clean, manually inputted interface. Built for simplicity, it allows teams to manage records directly without the friction of heavy backend databases.

**Key Features & What's Inside**
- Client Management: Dedicated sections for handling client records, updated in V1.1 with a brand-new layout section and a robust fix for soft-delete functionalities to ensure data integrity.
- Standup Tracking: A manual logging system designed to capture daily team updates, blockers, and progress updates in a centralized view.
- Sprint Needs: Structured tracking for current and upcoming sprint requirements, helping teams align on deliverables and priorities.
- Data Management: Straightforward interface controls allowing users to input, view, and organize operational data seamlessly.

**How It Works**
The application operates entirely on the client side via dir-dair.html. Because records are manually inputted, users can open the file directly in any modern web browser or serve it locally for quick data entry and tracking. Updates, deletions (including the newly fixed soft-delete mechanism), and layout interactions are handled dynamically within the interface, making it an agile tool for quick project tracking and offline-friendly record keeping.
